# How to Run the Monthly Job (No Terminal Needed)

## Option A — Double-click the .app (Recommended)

1. Drag launchers/Client Growth Report.app to Applications or Dock
2. Click it every month — Terminal opens automatically
3. Type OTP into the Chromium window when it appears
4. Walk away — report is emailed and committed

First time: right-click the app, choose Open, then Open again.

## Option B — Double-click the .sh in Finder

1. Right-click launchers/run_local_mac_linux.sh, choose Get Info
2. Open with: Terminal, click Change All
3. Now just double-click the .sh file anytime

## Option C — Terminal

cd to project folder, then: ./launchers/run_local_mac_linux.sh
